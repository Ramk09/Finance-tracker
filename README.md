# 💰 Finance Tracker

A simple and user-friendly web application for managing personal income and expenses.

Finance Tracker is built using Python, Flask, SQLite, HTML, and CSS. It allows users to create an account, securely log in, record their financial transactions, and keep track of their income, expenses, and balance.

---

## ✨ Features

- 👤 User Registration
- 🔐 User Login and Logout
- 💰 Add Income
- 💸 Add Expenses
- 🏷️ Categorize Transactions
- 📋 View Financial Transactions
- 📊 Track Total Income
- 📉 Track Total Expenses
- 💵 Calculate Current Balance
- 🗄️ SQLite Database
- 🎨 Simple and clean web interface
